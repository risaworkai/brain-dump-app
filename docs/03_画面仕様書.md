## 3. メイン画面（MAIN-01）

### 3.1 画面の目的

- **未ログイン時**: メールアドレス・パスワードで新規登録またはログインする。
- **ログイン後**: 種別・タイトル・期限・カテゴリ（任意）・本文・タグを入力し **`thought_entries`** に新規保存する。
- 保存済みメモ（`thought_entries` + 旧 `brain_dumps`）を一覧表示し、**完了・編集・削除** する。
- 種別・キーワードで一覧を絞り込む。

### 3.2 画面状態（切替）

| 状態 | 表示 | 非表示 |
|---|---|---|
| 未ログイン | `#auth-section`（認証フォーム）、ヘッダー・テーマ | `#app-main`、`#user-email`、`#logout-btn` |
| ログイン中 | `#app-main`、ヘッダー・メール・ログアウト・テーマ | `#auth-section` |

切替は `src/main.js` の `showAuthView()` / `showAppView()` で行う（ページ遷移なし）。

### 3.5 画面要素一覧

| # | 要素 | ID | 説明 |
|---|---|---|---|

| 3 | ログインメール | `#login-email` | type=email, 必須 |

| 7 | 登録メール | `#signup-email` | type=email, 必須 |
| 8 | 登録パスワード | `#signup-password` | type=password, minlength=6, 必須 |
| 9 | 新規登録ボタン | `#signup-btn` | submit |

認証エラーは **`alert()`** で表示（トーストは使わない）。

#### 3.5.2 ヘッダー（共通）

| 要素 | ID / クラス | 説明 |

#### 3.5.4 登録・編集フォーム（`#entry-form`）

| # | 要素 | 種別 | 必須 | 説明 |
|---|---|---|---|---|
| 1 | 編集 ID | `#edit-id` hidden | — | 更新対象の uuid |
| 2 | 編集元テーブル | `#edit-source` hidden | — | `thought_entries` または `brain_dumps` |
| 3 | 種別 | `#record-type` select | ○ | 4種別から選択 |
| 4 | タイトル | `#title` text | — | 任意 |
| 5 | 期限 | `#due-date` date | — | 任意（DB: `due_date`） |
| 6 | カテゴリ | `#category-id` select | — | 任意。先頭「（未選択）」= `NULL`。選択肢は DB の `categories` から動的生成 |
| 7 | 本文 | `#content` textarea | ○ | 必須 |
| 8 | タグ | `#tags` text | — | カンマ区切り |
| 9 | 保存 | `#submit-btn` | — | 新規時「保存（新規）」/ 編集時「更新する」 |
| 10 | 編集をやめる | `#cancel-edit` | — | 編集モード時のみ表示 |

カテゴリ欄のラッパーは `#category-field`。旧 `brain_dumps` 編集時は **非表示**（カテゴリは `thought_entries` のみ）。

#### 3.5.5 一覧パネル

| # | 要素 | ID | 説明 |
|---|---|---|---|
| 1 | 再読み込み | `#refresh-btn` | Supabase から再取得 |
| 2 | 種別フィルタ | `#filter-type` | 空=すべて |
| 3 | キーワード | `#filter-q` | タイトル・本文を部分一致（クライアント側） |
| 4 | 件数表示 | `#list-status` | 表示件数 / 全件数 / 旧データ件数 |
| 5 | リスト | `#entry-list` | カードの `<ul>` |

#### 3.5.6 各エントリカード（動的生成）

| 要素 | クラス | 説明 |
|---|---|---|
| 完了チェック | `.entry-card__check` | ラベル「完了」+ checkbox |
| 種別バッジ | `.badge` | 思いつき 等 |
| 旧データバッジ | `.badge--legacy` | `brain_dumps` 行のみ |
| 登録日時 | `.badge` | `登録: ` + `created_at` を日本語形式（日付・時刻） |
| 期限バッジ | `.badge--due` | `due_date` がある行のみ `期限: ` + 日付。過去日は `.badge--due-past` |
| カテゴリバッジ | `.badge--category` | `thought_entries` でカテゴリ設定時のみ `カテゴリ: ` + 名称 |
| タイトル | `.entry-card__title` | 空なら「（タイトルなし）」 |
| 本文プレビュー | `.entry-card__preview` | 最大約160文字 |
| タグ行 | `.entry-card__tags` | タグがある場合のみ |
| 編集 | ボタン | フォームに読み込み |
| 削除 | `.btn--danger` | confirm 後に削除 |
| 完了区切り線 | `.entry-list__separator` | 未完了と完了の境界に「完了」 |

完了済みカードは `.entry-card--done`（薄表示・取り消し線）。

## 4. 表示ルール

### 4.1 一覧の並び

1. **未完了** … `created_at` 降順（新しいほど上）
2. **完了** … 同様に降順。未完了ブロックの下に配置
3. 未完了と完了の間に区切り「完了」を表示（両方存在する場合）

### 4.2 旧データ（brain_dumps）の見た目

- 「旧データ」バッジを表示
- 種別は常に「思いつき」として表示
- タグ・期限・カテゴリは表示しない（`brain_dumps` に列が無いため）

### 4.3 メッセージ

| 種類 | 表示場所 | 例 |
|---|---|---|
| 成功・一般 | `#toast` | 保存しました / 完了にしました |
| エラー | `#toast`（赤系） | 更新に失敗: … |
| 環境エラー | `#env-warning` | Supabase 未設定（`.env.local` / `env.js` の案内） |

## 5. 操作と画面遷移

| 操作 | 動作（すべて `index.html` 内） |
|---|---|
| 初回アクセス（未ログイン） | 認証フォーム表示 |
| ログイン / 新規登録成功 | メモ UI 表示（`#app-main`） |
| ログアウト | 認証フォーム表示に戻る |
| 再読み込み（セッションあり） | メモ UI 表示 |

メモ操作は **同一ページ内** で完結。編集モード: 一覧の「編集」→ 左フォームに値が入り、保存ボタンが「更新する」に変わる。

## 6. バリデーション（画面側）

| 項目 | ルール |
|---|---|
| 本文 | 空・空白のみは不可。トーストで通知 |
| タイトル | 任意（新規 `thought_entries` は null 可） |
| カテゴリ | 任意。「（未選択）」のときは `category_id` を送らない／`null` |
| 旧データ更新 | タイトル空の場合は「（タイトルなし）」を DB に保存。カテゴリ欄は非表示 |

| 認証パスワード | 6 文字以上。不足時は `alert()` |
| 認証メール | `@` を含む形式。不正時は `alert()` |

## 7. テーマ・配色

| 項目 | 内容 |
|---|---|
| 切替方式 | `<html data-theme="dark">` または `data-theme="light"` |
| 初期表示 | `index.html` 内のインライン script が `localStorage` を読み、未設定時は **ダーク** |
| OS 連動 | しない（`prefers-color-scheme` は使用しない） |
| 配色 | 青系（ダーク: 濃紺背景 + 青アクセント / ライト: 淡青背景 + 青アクセント） |
| CSS 変数 | `src/style.css` の `:root` / `[data-theme="dark"]` / `[data-theme="light"]` |
