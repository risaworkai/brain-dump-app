### 3.2 SQL で確認

```sql
select tablename, rowsecurity
from pg_tables
where schemaname = 'public' and tablename = 'thought_entries';
```

`rowsecurity` が **true** であること。

```sql
select policyname, cmd, qual, with_check
from pg_policies
where schemaname = 'public' and tablename = 'thought_entries'
```

| thought_entries_select_own | SELECT | `user_id = auth.uid()` |
