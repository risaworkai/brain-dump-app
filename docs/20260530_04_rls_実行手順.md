# RLS 適用 — Supabase SQL Editor 実行手順

`docs/20260530_04_rls_brain_dumps_categories.sql` を Supabase に適用する手順です。

---

## 1. 事前確認

| 確認項目 | 内容 |
|---|---|
| 対象プロジェクト | ブレインダンプ用 Supabase プロジェクト |
| 前提 SQL | 未実行なら先に以下を適用する |
| | `20260530_02_user_id.sql` … `brain_dumps.user_id` |
| | `20260530_03_categories_user_id.sql` … `categories.user_id`（INSERT/UPDATE/DELETE ポリシー用） |

---

## 2. SQL Editor を開く

1. [Supabase Dashboard](https://supabase.com/dashboard) にログインする
2. 対象プロジェクトを選択する
3. 左メニュー **SQL Editor** をクリックする
4. **New query**（新規クエリ）をクリックする

---

## 3. SQL を貼り付けて実行

1. エディタに **`20260530_04_rls_brain_dumps_categories.sql` の中身だけ** を貼り付ける  
   - ファイルパス（`docs/...`）や Markdown は **含めない**
2. 右上の **Run**（または Ctrl+Enter）をクリックする
3. 下部に **Success. No rows returned** または成功メッセージが出れば OK

### エラーが出た場合

| エラー例 | 対処 |
|---|---|
| `column "user_id" does not exist`（categories） | 先に `20260530_03_categories_user_id.sql` を実行 |
| `policy ... already exists` | 本 SQL は `drop policy if exists` 付き。再度 Run してよい |
| 権限エラー | Dashboard から実行しているか確認（service role で実行される） |

---

## 4. 適用結果の確認

### 4.1 RLS が有効か

SQL Editor で次を実行する。

```sql
select tablename, rowsecurity
from pg_tables
where schemaname = 'public'
  and tablename in ('brain_dumps', 'categories');
```

`rowsecurity` が両方 **true** であること。

### 4.2 ポリシー一覧

```sql
select schemaname, tablename, policyname, cmd, roles, qual, with_check
from pg_policies
where schemaname = 'public'
  and tablename in ('brain_dumps', 'categories')
order by tablename, policyname;
```

期待されるポリシー:

| テーブル | ポリシー名 | 操作 | 条件 |
|---|---|---|---|
| brain_dumps | brain_dumps_select_own | SELECT | `user_id = auth.uid()` |
| brain_dumps | brain_dumps_insert_own | INSERT | WITH CHECK: `user_id = auth.uid()` |
| brain_dumps | brain_dumps_update_own | UPDATE | `user_id = auth.uid()` |
| brain_dumps | brain_dumps_delete_own | DELETE | `user_id = auth.uid()` |
| categories | categories_select_authenticated | SELECT | `true`（authenticated 全員） |
| categories | categories_insert_own | INSERT | WITH CHECK: `user_id = auth.uid()` |
| categories | categories_update_own | UPDATE | `user_id = auth.uid()` |
| categories | categories_delete_own | DELETE | `user_id = auth.uid()` |
