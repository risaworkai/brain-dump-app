# ブレインダンプアプリ 要求仕様書

## 1. 目的

- 思考・アイデア・AI 相談メモなどを素早く記録し、後から見返せる **個人用メモアプリ** を提供する。
- Supabase をバックエンドとし、ブラウザから CRUD および完了管理を行う。

## 2. 対象ユーザー

- 利用者は本人のみ（単一ユーザー・ローカル運用を想定）。
- **仮公開** として GitHub Pages からも閲覧・操作できる（スマホブラウザ含む）。
- **メールアドレス・パスワードでのログイン機能を搭載している**（Supabase Auth）。

## 3. システム構成

| 層 | 技術 |
|---|---|
| フロント | HTML / CSS / JavaScript（`index.html`, `src/main.js`, `src/style.css`） |
| ローカルサーバー | Node.js（`server.mjs`）。静的配信と `/env.js` による Supabase 設定の注入（PC 開発用） |
| 仮公開 | GitHub Pages（`main` ブランチ）。URL 例: `https://risaworkai.github.io/brain-dump-app/` |
| 起動（PC） | Windows: `起動.bat` → ブラウザで `http://127.0.0.1:5174/` |
| 起動（静的） | リポジトリ直下の `env.js` を読み込み。`index.html` 直開き（`file://`）でも可 |
| バックエンド | Supabase（PostgreSQL） |
| DB テーブル | `thought_entries`（新規）、`brain_dumps`（旧データ互換）、`categories`（カテゴリマスタ） |

### 3.1 設定ファイル

| ファイル | 用途 |
|---|---|
| `.env.local` | PC 用の正本。Git には含めない |
| `env.js` | フロントが import する Supabase 接続情報。GitHub Pages 用にリポジトリへ含める（仮公開） |
| `.env.example` | 見本（アプリは読まない） |

`env.js` の更新: `公開用-env更新.bat`（内部で `scripts/sync-env-from-local.mjs`）が `.env.local` から生成する。

## 4. 機能要件

### 4.1 メモ登録（新規）

- 種別（思いつき / AI相談 / プロンプト / 学習メモ）、タイトル（任意）、期限（任意）、本文（必須）、タグ（カンマ区切り、任意）、カテゴリ（任意）を入力して保存できる。
- カテゴリは **マスタテーブル `categories`** の選択肢からドロップダウンで選ぶ（未選択可）。
- 新規保存先は **`thought_entries`** とする。
- 作成日時・更新日時は DB 側またはクライアントで設定する。

### 4.2 メモ一覧表示

- `thought_entries` と `brain_dumps` の両方から取得し、**作成日時の新しい順**でマージ表示する。
- 各行に種別・登録日時・タイトル・本文プレビュー・タグ・期限（ある場合）・カテゴリ名（設定されている場合）を表示する。
- 旧 `brain_dumps` 行には **「旧データ」** と分かる表示をする。
- 種別フィルタ・キーワード検索（タイトル・本文）で絞り込める。

### 4.3 完了（is_done）

- 各行に **完了チェックボックス** を表示する。
- チェック ON の行は一覧の **下部** にまとめて表示する（未完了は上部、新しい順）。
- チェックの更新は、行が属するテーブル（`thought_entries` または `brain_dumps`）に対して行う。

### 4.4 メモ編集

- 既存行をフォームに読み込み、更新できる。
- `thought_entries`: 種別・タイトル・本文・タグ・期限（`due_date`）・カテゴリを更新。カテゴリはドロップダウンで選択する（未選択可）。
- `brain_dumps`（旧データ）: タイトル・本文のみ更新。

### 4.5 メモ削除

- 確認ダイアログのあと、該当テーブルから行を削除する。

### 4.6 表示テーマ

- ヘッダーから **ダーク** / **ライト** を選択できる。
- 選択はブラウザの `localStorage` に保存し、次回起動時も維持する。
- OS の外観設定（`prefers-color-scheme`）には連動しない。

### 4.7 フィードバック

- 成功・失敗をトーストまたはバナーで表示する。
- Supabase 未設定時（`env.js` が無い・空など）は警告を表示する。
- `due_date` 列が無い等で保存失敗した場合、SQL 追加手順を促すメッセージを表示する。

### 4.8 カテゴリ管理

- メモ（`thought_entries`）に **カテゴリ** を設定できる。
- カテゴリの選択肢は、専用の **マスタテーブル `categories`** で管理する（名称などをマスタ側で保持）。
- メモの **新規投稿・編集** 時に、マスタから読み込んだ選択肢を **ドロップダウン** で選べる。
- カテゴリの入力は **必須としない**（未選択のまま保存・更新できる）。
- **一覧画面** に、カテゴリが設定されている行は **カテゴリ名** を表示する（未設定の行は表示しない、または「—」等で未設定と分かる表示とする）。

### 4.9 認証（ログイン）

- **メールアドレス・パスワード** による **新規登録・ログイン・ログアウト** を提供する。
- 認証方式はメール＋パスワードのみ（OAuth・マジックリンクは対象外）。
- **メール確認（confirm email）は行わない**（Supabase 側で Confirm email を無効化する）。
- パスワードは **6 文字以上**。
- ログイン・新規登録成功後は **同一 `index.html` 内でメイン画面を表示** する（ページ遷移なし）。
- 未ログイン時は **`index.html` 上で認証フォームのみ表示** し、メモ操作 UI は非表示とする。
- ログイン中はヘッダーに **ログイン中のメールアドレス** を表示する。
- 認証エラーは **`alert()`** で通知する（トーストはメモ操作向けのまま）。

## 5. 非機能要件

| 項目 | 内容 |
|---|---|
| 可用性 | Supabase の標準可用性に準拠 |
| 性能 | 一覧・保存・更新・削除は通常操作で体感待ちが少ないこと |
| セキュリティ（簡易版） | Supabase は HTTPS。PC では anon キーを `.env.local` に保持。仮公開では `env.js` に同キーを含め GitHub 上も参照可能。Auth により未ログインはメイン画面不可。RLS オフのため **本番公開は非推奨** |
| 保守性 | 新規は `thought_entries` に集約。旧 `brain_dumps` は読み取り互換を維持 |
| 操作性 | PC・スマホブラウザ。レスポンシブレイアウトで狭い画面にも対応 |

## 6. スコープ

### 6.1 対象範囲

- メモの作成・一覧・編集・削除・完了チェック
- 種別・タグ・期限・カテゴリ（マスタ `categories`、任意入力）
- 表示テーマ（ダーク / ライト）
- 一覧フィルタ（種別・キーワード）
- 旧 `brain_dumps` データの表示・互換操作
- ローカルサーバー経由の起動（`起動.bat`）
- 仮公開（GitHub Pages + `env.js`）
- **認証**（新規登録・ログイン・ログアウト・ログイン中メール表示）

### 6.2 対象外

- OAuth・マジックリンク・パスワードリセット UI
- メール確認（confirm email）フロー
- RLS（将来版）
- 画像・ファイル添付
- `derivatives`（JSONB）の UI
- 他ユーザーとの共有・通知

## 7. 受け入れ条件

- `起動.bat` 実行後、黒い窓に **「Supabase: 設定 OK」** と表示される。
- ブラウザで `http://127.0.0.1:5174/` を開き、アプリ名 **「ブレインダンプ」** が表示される。
- GitHub Pages の URL（例: `https://risaworkai.github.io/brain-dump-app/`）を開き、同様にアプリが表示され、スマホからも操作できる。
- リポジトリに `env.js` があり、PC で `index.html` を `file://` で開いても Supabase に接続できる（`env.js` が無い場合は環境警告バナー）。
- 本文未入力では保存できない。
- 新規保存した行は `thought_entries` に保存され、一覧に表示される。
- 完了チェックで `is_done` が更新され、完了行が一覧下部に移動する。
- 旧 `brain_dumps` の行も一覧に表示され、編集・削除・完了チェック（`is_done` 列追加後）ができる。
- 期限を入力して保存した `thought_entries` 行に、一覧で「期限: ○○」が表示される。
- テーマを切り替えると、画面の配色がダーク / ライトで変わり、再読み込み後も選択が保持される。
- 新規・編集フォームでカテゴリをドロップダウンから選択でき、未選択のまま保存できる。
- カテゴリを設定した `thought_entries` 行に、一覧でカテゴリ名が表示される。
- 未ログインで `index.html` を開くと、認証フォーム（ログイン・新規登録）のみ表示され、メモ UI は非表示になる。
- `index.html` 上でメール・パスワード（6 文字以上）により新規登録でき、成功後メイン画面が表示される。
- `index.html` 上で登録済みアカウントでログインでき、成功後メイン画面が表示される。
- ログイン中、ヘッダーにログイン中のメールアドレスが表示される。
- 「ログアウト」でセッションが解除され、認証フォーム表示に戻る。
- 認証失敗時、`alert()` でエラーが表示される。
